# Public documents

This public repository hosts documents for apps maintained by pagratios. It contains no application source code, credentials, or user data.

## ReBloom

The ReBloom privacy policy is maintained at [`rebloom/privacy/index.html`](rebloom/privacy/index.html) and published at <https://pagratios.github.io/public-docs/rebloom/privacy/> via GitHub Pages.

Pages serves the `main` branch from the repository root. Keep the published policy in sync with the app's actual data handling and update its effective date when the policy changes. Review integrations, permissions, retention, and contact information before each material update. The policy is plain HTML and needs no build step.
